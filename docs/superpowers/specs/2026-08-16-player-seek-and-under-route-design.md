# 播放器跳转时间拆分与特殊源入口改名设计

## 目标

恢复上游播放器的“快捷快进配置”及控制栏按钮，同时保留当前“快进/倒退时间”，使两者分别控制不同操作；删除 `/sp` 的自定义入口映射，并把特殊源唯一入口从 `/r18` 改为 `/under`。

## 播放器行为

播放器保留两个互不影响的本机设置：

- `快捷快进配置`：沿用上游的 `quickForwardSeconds` 存储键，默认 90 秒，只控制 P 键和控制栏“快捷快进”按钮。
- `快进/倒退时间`：使用新的独立存储键 `seekStepSeconds`，默认 10 秒，只控制左右方向键。

设置菜单顺序固定为：

1. 跳过片头片尾
2. 快捷快进配置
3. 快进/倒退时间
4. 跳过配置

恢复的控制栏按钮采用上游 `main` 的图标、位置、提示和移动端竖屏隐藏规则。左右方向键继续钳制到 `[0, duration]`，并显示实际快进或快退时长。

## 数据与兼容性

`quickForwardSeconds` 历史上属于上游快捷快进功能，因此继续归“快捷快进配置”所有。新增的 `seekStepSeconds` 没有历史值时使用 10 秒，不把旧值复制到两个配置，也不增加迁移标记。

输入值必须是大于 0 的有限数，保存时四舍五入且最小为 1 秒。两个设置分别写自己的 localStorage 键，修改其中一个不会改变另一个。

## 特殊源路径

- 删除 `/sp` 页面中的自定义路径输入框、保存/清除按钮和相关说明。
- 删除 `special_source_path` cookie 常量、读写函数、路径规范化函数及对应测试。
- 删除 middleware 中的自定义路径重定向。
- 将 App Router 页面目录从 `src/app/r18` 改为 `src/app/under`。
- 将特殊源路径常量改为语义化名称并设为 `/under`，同步更新搜索页、侧栏、后台说明、隔离注释和测试。
- `/r18` 不保留页面、redirect 或 rewrite；更新后访问它按不存在的路由处理。

特殊源开关 cookie `special_source=1` 保持不变。播放页等离开入口后的页面仍通过 `special=1` 查询参数延续特殊源上下文，因此收藏、播放记录和搜索历史的双向隔离逻辑不改变，只更换入口 pathname。

## 测试与验收

实施按红—绿顺序：

1. 先把特殊源上下文测试改为 `/under`，并删除自定义路径测试，确认旧实现下测试失败。
2. 先为两个独立时间配置的默认值、存储键及输入规范化编写测试，确认待实现模块缺失导致失败。
3. 写最少实现让针对性测试通过，再接入播放器 UI 和按键。
4. 运行完整 Jest、TypeScript 类型检查和格式检查。
5. 全库搜索确认生产代码、测试和用户文案中不再包含 `/r18`、`R18_PATH`、`special_source_path` 或 `SpecialSourcePathForm`。
6. 核对播放器源码中两个设置按指定顺序出现，P 键/按钮使用快捷快进值，左右方向键使用独立快进/倒退值。

## 范围外

不修改特殊源服务端筛选协议、`special=1` 参数、特殊源开关 cookie、全屏播放器原有的固定 ±5 秒按钮，也不改动未跟踪的 `custom-theme.css`。
